## Installation

### 1. Clone the repository:
   ```bash
   git clone https://github.com/Muurthe/showcase-portfoliov2.git
   cd showcase-portfolio
   ```

### 2. Install dependencies
  ```bash
  npm install
  ```

### 3. Start the development server
  ```bash
  npm run dev
  ```

Your app will be available at:
http://localhost:3000
